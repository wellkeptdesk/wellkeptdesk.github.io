# whim/

DI 10.5 Whimsigothic test assets.

- `lamp/`: Reading lamp widget (moon phase computed locally, reading timer, pages per night, seven-night candle row). Saved in this browser only (localStorage `whim-lamp-v1`), never reads Notion, no credentials. Params: `theme=dark|light`, `demo=1`.
- `art/`: cover, icon, pillar ornament, six book emblems, drawn in code.
- `fonts/`: Mystery Quest (lamp display face; Uncial Antiqua kept for reference) (SIL OFL 1.1, licence included). Body text uses Cormorant Garamond from `kit/fonts`.
