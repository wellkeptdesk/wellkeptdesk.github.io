# Aero set (DI 8.0 Frutiger Aero study)

Original art and one widget for a Frutiger-Aero-derived wellness template. All artwork is drawn in code
(no stock or archive images). Palette and decisions are documented in the Design Intelligence KB
(`COLOR_INTELLIGENCE/PALETTE_LIBRARY/frutiger-aero.md`).

| Item | URL | Notes |
|---|---|---|
| Water widget | `/aero/water/` | `goal` (default 8), `theme=night` (default) \| `day`/`light`. Local interactive: counts stay in this browser on this device, nothing is sent anywhere and nothing reads Notion. `demo=1` shows sample data and does not save. |
| Cover | `/aero/art/cover-hub.jpg` | 2400×800 |
| Gallery cards | `/aero/art/card-{water,move,sleep,mind}.jpg` | 1600×900 |
| Area strip | `/aero/art/strip-{water,move,sleep,mind}.jpg` | 1600×560, one light mood per area |
| Icons | `/aero/art/icon-{hub,water,move,sleep,mind}.png` | 280×280, transparent |

Fonts: Open Sans (SIL OFL 1.1, `fonts/OFL-open-sans.txt`), self-hosted.
