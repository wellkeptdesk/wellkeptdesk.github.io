# cyber/

DI 8.0 Cybercore test assets.

- `signal/`: Signal check widget (energy, focus, mood 1-5 per day, 14-day traces). Saved in this browser only (localStorage `cyber-signal-v1`), never reads Notion, no credentials. Params: `theme=dark|light`, `demo=1`.
- `art/`: cover and icon, drawn in code.
- `fonts/`: Michroma (SIL OFL 1.1, licence included). Mono text uses IBM Plex Mono from `kit/fonts`.
