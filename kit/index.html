WellKeptDesk widgets

Small, quiet widgets for Notion pages. Copy a link, paste it into Notion, choose “Create embed”, then set the embed height shown under each card. Settings live after the # in the link, so nothing is sent to a server.

Options: palette (serein, lavender-oat, linen-sage, espresso, sea-glass, olive, champagne, porcelain, terracotta, honey, midnight, sky-ledger, lavender-haze, ink-brass, ink, fern, oxblood) · theme (light, dark, auto) · style (editorial, soft, minimal, ledger).
