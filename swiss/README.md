# Swiss set (DI 8.0 Swiss Modernism study)

Original art and one widget for a Swiss-Modernism-derived weekly planner. Art is drawn in code from grid relations
(asymmetric balance, one red plane, a counted rhythm of bars, flush-left grotesque type); no poster is copied.

| Item | URL | Notes |
|---|---|---|
| Week grid widget | `/swiss/grid/` | Click a cell: planned, again: done, again: empty. `from`/`to` hours (default 8-18), `theme=light\|dark` (default follows system), `demo=1` sample week, never saved. Local interactive: saved in this browser on this device only, nothing is sent, nothing reads Notion. |
| Cover | `/swiss/art/cover-paper.jpg`, `cover-black.jpg` | 2400x800, meaning kept in y 226-574 (Notion's visible band) |
| Icon | `/swiss/art/icon.png` | 280x280 |

Font: Inter (SIL OFL 1.1), self-hosted in `/kit/fonts/`.
